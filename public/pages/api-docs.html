Спецификация REST API

Полное описание эндпоинтов серверной части интернет-магазина MODUL.HAUS. Базовый URL: http://localhost:3030. Все ответы возвращаются в формате JSON UTF-8.

1. Каталог и серии

GET /api/catalog/series
Возвращает полный список доступных линеек домов и бань с начальными ценами и категориями.
Пример ответа (200 OK):
[ { "id": 1, "slug": "altai", "name": "Алтай", "category": "houses", "starting_price": 3868000, "min_area": 70.5 } ]
GET /api/catalog/presets
Список популярных готовых карточек проектов для витрины главной страницы.

2. Конфигуратор и каскадный подбор

GET /api/configurator/:seriesSlug/options
Загрузка параметров серии (габариты, доступные пристройки, цвета) для отрисовки селекторов конфигуратора.
GET /api/configurator/:seriesSlug/photos
Каскадный подбор фотографий по выбранным фильтрам: размер, цвет, терраса/крыльцо с фолбеком на базовый экстерьер и планировку.
Query параметры:
configKey: "9x9.5" color: "bronze" entrance: "terrace" terraceType: "covered"

3. Авторизация и профиль клиента

POST /api/auth/send-push-code
Генерация 4-значного кода подтверждения для регистрации/входа по номеру телефона РФ. Сессия живет 5 минут.
Тело запроса (JSON):
{ "phone": "+7 (999) 123-45-67", "name": "Алексей Иванов", "password": "secretPassword123", "passwordConfirm": "secretPassword123" }
POST /api/auth/register-phone
Проверка 4-значного Push-кода, создание пользователя в базе данных и выдача JWT-токена на 30 дней.
POST /api/auth/login
Вход по связке email/телефон + пароль. Возвращает JWT токен.
GET /api/auth/my-orders Требуется JWT токен
Возвращает список всех заказов текущего авторизованного пользователя с деталями комплектации и статусом производства.

4. Заказы и платежный шлюз

POST /api/orders
Создание нового заказа из корзины с присвоением номера DK-ГГГГММДД-ХХХХ и отправкой email-уведомления менеджеру.
POST /api/orders/:id/pay
Инициализация платежа через официальный API ЮKassa или запуск локального интерактивного тестового шлюза (Sandbox).
POST /api/orders/:id/confirm-payment
Фиксация факта успешной оплаты и автоматический перевод статуса заказа в PAID.
GET /api/orders/:id/contract
Генерация официального договора поставки, сметы и спецификации в формате для печати или сохранения в PDF с реквизитами завода и штампом оплаты.
POST /api/orders/webhook/yookassa
Официальный вебхук ЮKassa для асинхронного подтверждения платежей сервером эквайринга. Возвращает 200 OK.

5. Лиды и заявки

POST /api/leads
Отправка заявки на обратный звонок или расчет сметы с валидацией российского номера телефона.

6. Панель администратора

GET /api/admin/analytics Требуется JWT Admin
Сводная исполнительная аналитика: общая выручка, конверсия в оплату, средний чек, количество зарегистрированных клиентов, распределение статусов и динамика продаж за 7 дней.
GET /api/admin/orders Требуется JWT Admin
Полный список всех заказов магазина со всеми позициями и контактами клиентов.
PATCH /api/orders/:id/status Требуется JWT Admin
Смена этапа производства заказа: NEW → PAID → IN_PRODUCTION → DELIVERING → COMPLETED.
GET /api/admin/outbox Требуется JWT Admin
Журнал всех отправленных почтовых уведомлений (FormSubmit / SMTP) со статусами доставки.
POST /api/admin/settings/test-mail Требуется JWT Admin
Проверка подключения к SMTP серверу (Mail.ru, Yandex) и отправка проверочного тестового письма.
POST /api/admin/settings/test-telegram Требуется JWT Admin
Проверка подключения к Telegram Bot API и отправка проверочного сообщения в чат или канал.

Архитектурная карта проекта

Двухуровневая интерактивная декомпозиция архитектуры интернет-магазина модульных домов и бань MODUL.HAUS. Верхний уровень описывает общую логическую схему взаимодействия подсистем. В каждый модуль на схеме можно «провалиться» — на втором уровне для каждого сложного блока построена отдельная подробная схема Archify с описанием внутренних функциональных элементов, файлов и потоков данных.

Бэкенд стек
Node.js 24 + Express 4
База данных
SQLite 3 (WAL mode)
Шлюз оплаты
ЮKassa API / Sandbox
Почтовый сервис
Dual Relay: FormSubmit + SMTP

Декомпозиция блока «Клиентский JS/CSS»

Показывает, из каких именно функциональных элементов состоит браузерный код интернет-магазина. Каждый файл изолирован в своем пространстве имен и решает строго свою задачу.

docs/archify/sub-frontend.html (Architecture)
Во весь экран ↗
Компонент Файл Внутренние функции и роль
State Machine Конфигуратора public/js/configurator.js Хранит выбранную серию, габариты, цвет и пристрой. Управляет активными классами кнопок и переключает состояние без перезагрузки страницы.
Слайдер и Галерея public/js/configurator.js Принимает массив слайдов от сервера, рендерит миниатюры, поддерживает пролистывание стрелками/кликами и зум планировок.
Калькулятор Сметы public/js/configurator.js Динамически суммирует: базовая стоимость серии + наценка за размер из каталога + стоимость пристроя (крыльцо 180 тыс. руб., терраса открытая 260 тыс. руб. или закрытая 420 тыс. руб.).
Хранилище Корзины public/js/cart.js Использует localStorage['doka_cart']. Синхронизирует корзину между вкладками и пересчитывает счетчики в шапке сайта.
Гейткипер Сделки public/js/cart.js Блокирует переход к оплате для неавторизованных пользователей, открывая модальное окно регистрации по push-коду.
Модалка Чекаута public/js/cart.js Принимает контакты покупателя, адрес участка и отправляет заказ на бэкенд, после чего открывает платежный шлюз.
Панель Админа (SPA) public/js/admin.js Одностраничное приложение управления магазином: фильтры медиатеки, редактирование цен серий, смена статусов заказов и журнал писем.
Дизайн-система public/css/style.css CSS-переменные цветов, отступов и радиусов, адаптивная мобильная сетка, плавающие шапки и анимации шторок.

Декомпозиция блока «Express HTTP Сервер»

Главный серверный узел server.js. Настраивает глобальные middleware, управляет раздачей статики по стандарту хостинга и распределяет входящие запросы по специализированным роутерам.

docs/archify/sub-server.html (Architecture)
Во весь экран ↗
Слой Файл / Маршрут Назначение и логика
Статический Роутер server.js → public/pages Отдает чистые URL (/houses, /saunas, /profile) и файлы .html. Предоставляет алиасы /houses и /saunas для обратной совместимости фото.
JWT Guard Middleware src/middleware/auth.js requireAuth: строгая проверка токена для админки (401 при отсутствии). optionalAuth: мягкое считывание пользователя для связки заказов.
Публичные Роутеры /api/catalog, /api/configurator Отдают каталоги серий, габаритов и фото без требования авторизации.
Транзакционные Роутеры /api/orders, /api/auth Создание заказов, инициация оплаты и генерация кодов подтверждения.
SPA Фолбек app.use((req, res)) Перенаправляет любые неизвестные не-API запросы на index.html, предотвращая ошибки 404 при обновлении страниц.

Механизм отвечает за автоматическое связывание физических файлов фото на диске с параметрами конфигуратора в базе SQLite и динамический расчет сметы.

docs/archify/sub-configurator.html (Architecture)
Во весь экран ↗
Этап Код / Файл Описание механизма
Индексация папок src/db/seed.js Сканирует public/catalog/houses и public/catalog/saunas. Парсит имена вида 9x9.5__p4259000, извлекая ширину, длину и базовую цену.

2. Базовый фолбек src/routes/configurator.js Если фото пристроя в каталоге нет, автоматически подставляет базовый экстерьер дома без пристроя (entrance_kind = 'base').
3. Подтяжка чертежа src/routes/configurator.js Если в найденном наборе нет файла планировки (plan), чертеж подтягивается из базового комплекта этого же цвета.

Декомпозиция блока «Модуль Авторизации»

Система регистрации клиентов без паролей через одноразовые 4-значные коды из push-уведомлений или SMS, с автоматической склейкой истории заказов.

docs/archify/sub-auth.html (Architecture)
Во весь экран ↗
Элемент Файл / Эндпоинт Назначение
Генератор Кода POST /api/auth/send-push-code Генерирует 4 случайные цифры, сохраняет сессию в Map с временем жизни 5 минут и отправляет пуш.
Сессии в Памяти verificationSessions (RAM) Изолированное хранилище кодов в оперативной памяти сервера без записи на диск для безопасности.
Автопривязка Заказов UPDATE orders SET user_id = ? При первой регистрации находит все ранее оформленные гостевые заказы с тем же телефоном и привязывает их к аккаунту.
Эмиттер Токенов jsonwebtoken (JWT_SECRET) Формирует подписанный токен с id, телефоном и ролью клиента, действительный в течение 30 дней.

Декомпозиция блока «Заказы и Платежи»

Полный цикл обработки покупок: от формирования корзины и валидации номеров до онлайн-оплаты через шлюз и мониторинга этапов фабричной сборки.

docs/archify/sub-orders.html (Architecture)
Во весь экран ↗
Компонент Файл / Модуль Роль в системе
Создание Заказа POST /api/orders Валидирует телефон РФ, вычисляет сумму корзины, присваивает номер DK-YYYYMMDD-XXXX и статус NEW.
Платежный Шлюз POST /api/orders/:id/pay При наличии ключей в настройках создает сессию в ЮKassa. Иначе открывает интерактивный Sandbox шлюз.
Подтверждение Оплаты POST /api/orders/:id/confirm-payment Фиксирует транзакцию, переводит статус заказа в PAID и триггерит отправку email администратору.
Контроль Производства PATCH /api/orders/:id/status Администратор последовательно переключает заказ: IN_PRODUCTION → DELIVERING → COMPLETED.

Декомпозиция блока «Сервис Уведомлений»

Служба src/services/mailer.js гарантирует моментальное получение оповещений менеджером на почту watislove@internet.ru.

docs/archify/sub-mailer.html (Architecture)
Во весь экран ↗
Канал доставки Технология Особенности
Канал 1: FormSubmit Relay HTTPS fetch(formsubmit.co/ajax/...) Работает без паролей и логинов. Надежно обходит спам-фильтры и гарантирует доставку писем при любых настройках хостинга.
Канал 2: Прямой SMTP nodemailer (smtp.mail.ru:465) Используется при указании пароля приложения в админке для отправки писем напрямую с доменного ящика компании.
Журнал Outbox data/outbox.log Локальный текстовый лог формата JSON Lines. Отображается в админке во вкладке «Журнал писем» для аудита доставки.

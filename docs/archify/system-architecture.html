Архитектурная карта проекта

Двухуровневая интерактивная декомпозиция архитектуры интернет-магазина модульных домов и бань MODUL.HAUS. Верхний уровень описывает общую логическую схему взаимодействия подсистем. В каждый модуль на схеме можно «провалиться» — на втором уровне для каждого сложного блока построена отдельная подробная схема Archify с описанием внутренних функциональных элементов, файлов и потоков данных.

Декомпозиция клиентского фронтенда (JS / CSS)

Клиентский интерфейс построен на нативном JavaScript (Vanilla JS ES6+) без тяжелых фреймворков. Логика разделена по изолированным модулям-синглтонам (IIFE), хранящим свое внутреннее состояние.

docs/archify/sub-frontend.html (Architecture)
Во весь экран ↗
Файл / Модуль Функциональные обязанности Взаимодействие
public/js/configurator.js State Machine конфигуратора: размер, цвет фасада (бронза, бежевый, графит), терраса/крыльцо, слайдер фото, зум и пересчет сметы. Шлет запросы в /api/configurator, передает готовую сборку в Cart.addItem().
public/js/cart.js Хранилище корзины в localStorage ('doka_cart'), выдвижная шторка Drawer, гейткипер сделки и модалка чекаута. Перехватывает клик «Оформить заказ». Если JWT нет, показывает push-модалку, затем плавно открывает чекаут.
public/js/admin.js Клиентское SPA админ-панели: переключение табов (каталог, фото, CMS, настройки, заказы, журнал писем). Отправляет запросы с заголовком Authorization: Bearer <token> в /api/admin/*.
public/js/app.js Общие функции страниц: липкая шапка со скроллом, бургер-меню, плавный скролл и системные тосты-уведомления. Инициализируется на всех публичных страницах.
public/css/style.css Глобальная дизайн-система: CSS-переменные, адаптивная сетка, типографика, оформление корзины и карточек. Подключается на всех клиентских страницах.

Декомпозиция Express HTTP Сервера (server.js)

Файл server.js является точкой входа Node.js приложения. Он собирает промежуточные обработчики (middleware), настраивает раздачу статических папок по стандартам хостинга и распределяет запросы по изолированным роутерам.

docs/archify/sub-server.html (Architecture)
Во весь экран ↗
Слой / Маршрут Файловый источник Назначение
/catalog, /houses, /saunas public/catalog/ Раздача фотографий каталога. Старые пути /houses/... алиасированы для 100% обратной совместимости.
/pages, /, /*.html public/pages/ Раздача чистых HTML-страниц: index.html, houses.html, saunas.html, profile.html, admin.html.
/css, /js, /images public/ Клиентские стили, скрипты и статическая графика бренда.

/api/health, SPA Fallback server.js Healthcheck для мониторинга и отдача index.html при непредвиденных путях без падения сервера.

Механизм конфигуратора и каскадный подбор фото

Клиентский скрипт public/js/configurator.js работает в связке с роутером src/routes/configurator.js. Поддерживается динамический выбор габаритов, цветов фасада (бронза, бежевый, графит) и пристроев (крыльцо, открытая/закрытая терраса).

docs/archify/sub-configurator.html (Architecture)
Во весь экран ↗
Этап каскада Условие выборки SQLite Результат
1. Точное совпадение entrance_kind = ? AND terrace_type = ? AND color = ? Если фотографии с данным пристроем физически есть в каталоге, отдаются именно они.
2. Базовый фолбек entrance_kind = 'base' AND color = ? Если фото выбранного пристроя нет в папке, показываются качественные базовые фото дома без заглушек.
3. Гарантия планировки kind = 'plan' AND color = ? Если в найденном сете нет файла планировки, чертеж автоматически подтягивается из базового набора.

Механизм аутентификации и Push-верификации

По бизнес-логике продолжение сделки в корзине доступно только после входа или регистрации. Пользователь вводит номер телефона, получает 4-значный код подтверждения и мгновенно переходит к чекауту.

docs/archify/sub-auth.html (Architecture)
Во весь экран ↗
Компонент Путь / Эндпоинт Назначение
Гейткипер public/js/cart.js Перехватывает клик «Оформить заказ». Если JWT нет, показывает всплывающее окно входа/регистрации.
Генерация кода POST /api/auth/send-push-code Создает 4-значный код, сохраняет в Map сессий на 5 минут и триггерит системный Web Push / SMS.
Регистрация POST /api/auth/register-phone Проверяет код, хэширует пароль bcrypt (10 rounds), связывает старые заказы и выдает JWT на 30 дней.
Бесшовный переход Cart.openCheckoutModal() Сразу после ответа 201 модалка авторизации закрывается и плавно открывает форму оформления заказа.

Почтовый сервис Dual Relay (src/services/mailer.js)

Чтобы гарантировать 100% доставку писем администратору (watislove@internet.ru), сервис использует параллельный двойной релей.

docs/archify/sub-mailer.html (Architecture)
Во весь экран ↗
Канал доставки Протокол / API Особенности и отказоустойчивость
1. FormSubmit Relay POST https://formsubmit.co/ajax/watislove@internet.ru Работает через защищенный HTTPS AJAX релей. Доставляет письма без необходимости ввода пароля от почты и исключает блокировки Mail.ru.
2. Прямой SMTP nodemailer: smtp.mail.ru:465 (SSL) Активируется, если в панели администратора введен пароль приложения (smtp_pass). Отправляет письмо напрямую от имени домена.
3. Журнал Outbox data/outbox.log Каждое отправленное письмо фиксируется в локальном логе и доступно для аудита во вкладке админки «Журнал писем».

Схема базы данных SQLite (ERD)

Локальный файл data/store.db управляется через библиотеку better-sqlite3. Включен режим журналирования WAL (Write-Ahead Logging) для максимальной производительности чтения.

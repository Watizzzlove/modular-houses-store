# MODUL.HAUS — Интернет-магазин модульных домов и бань с интерактивным конфигуратором

Учебный проект по дисциплине «Веб-программирование» (магистратура).

Веб-приложение для презентации, конфигурирования, оформления и покупки современных модульных домов и бань. Проект вдохновлен архитектурой и сервисом [dokabani.ru](https://dokabani.ru/) и реализован в соответствии с дизайн-прототипом в Figma.

---

## 🎯 Ключевые возможности

1. **Интерактивный конфигуратор модульных домов и бань**:
   - Автоматический расчет стоимости силового каркаса, цвета отделки фасада и пристроев.
   - Пошаговая динамическая фильтрация входной группы:
     - Нет лишней опции «Без пристроя» (базовое строение отображается по умолчанию).
     - Выбор «Крыльцо» или «Терраса» с отменой кликом (возврат к базовой комплектации).
     - Выбор исполнения террасы («Крытая» / «Открытая»).
     - Выбор габаритов пристроя с динамическим расчетом стоимости.
   - Умная галерея:
     - Загрузка реальных фотографий для конкретной связки параметров (`серия/размер/пристрой/цвет`).
     - Карточка-заглушка **«Фотографии в обработке»** при отсутствии фото в каталоге (без подмены ракурсами базового дома).
   - Кнопка **«Получить расчёт»** с оранжевой подсветкой (скролл к форме заявки с предзаполнением сметы).
   - Кнопка **«Добавить в корзину»** для добавления выбранной комплектации.

2. **Клиентская витрина**:
   - Главная страница (`index.html`) с промо-экраном, преимуществами, популярными проектами и формой связи.
   - Страница модульных домов (`houses.html`) с переключателем серий («Алтай», «Тайга», «Таганай», «Урал 2.0»).
   - Страница модульных бань (`saunas.html`) с переключателем серий («Классика», «Тайга», «Таганай», «Урал»).
   - Адаптивная верстка под десктоп и мобильные устройства.

3. **Корзина и оформление заказа**:
   - Боковая шторка корзины с полным списком выбранных опций (серия, размеры, цвет, пристрой, цена).
   - Сохранение состояния корзины в `localStorage`.

4. **Панель администратора (`admin.html`)**:
   - Авторизация администратора по JWT-токену.
   - Управление проектами и ценами.
   - Управление каталогом фотографий (загрузка и удаление фото).
   - Просмотр заказов клиентов и заявок с сайта.

## 🚀 Установка и запуск

```bash
# Клонирование репозитория
git clone https://github.com/Watizzzlove/modular-houses-store.git
cd modular-houses-store

# Установка зависимостей
npm install

# Запуск сервера разработки
npm start
# или
node server.js
```

Сервер запустится по адресу:
- Сайт: **http://localhost:3030/**
- Каталог домов: **http://localhost:3030/houses.html**
- Каталог бань: **http://localhost:3030/saunas.html**
- Панель администратора: **http://localhost:3030/admin.html** (логин `admin@modul-haus.ru`, пароль `admin123`)
